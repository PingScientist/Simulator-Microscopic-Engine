# 三分鐘展示與預備回答

0:00–0:40：第一屏按「啟動熱機」，說明粒子受位能、摩擦與隨機踢擊。比較熱浴設定溫度與粒子動能尺度；前兩圈暖機不進平均。

0:40–1:15：沿四階段說明高溫放鬆輸出功、低溫收緊輸入功；按完成一循環，指出最近完整循環功與曲率迴圈。單圈可能波動，不保證每次正功。

1:15–1:55：掃描 A/B 展示溫差與 ln 曲率比的線性關係，指出 95% CI、理論與殘差。需要時間時預先跑完，再透過 JSON 保存；不得把未執行的圖說成現跑。

1:55–2:30：切換操作時間掃描的功與功率；加入搬運，說明平移功是成本且已納入淨功。速度掃描使用同時序固定中心對照。

2:30–3:00：切雙週期，解釋平滑週期位能與各自理論參考；最後儲存 JSON 或匯出 CSV。提交只需 HTML。

預備回答：

- 「為什麼不每幀把速度縮放到溫度？」因為這會改變動力學與速度分布；本模型用符合漲落耗散關係的熱浴。
- 「熱浴升到 3，粒子為何不是剛好 3？」有限熱化時間、有限粒子波動與非平衡漂移。
- 「能量不守恆？」系統與熱浴、外部控制交換能量；檢查 ΔE=Win+Q 加上數值殘差，以及步長收斂。
- 「週期模式為何不是同一條理論線？」全域位能形狀改變；局部曲率相同不等於配分函數相同。
- 「慢是不是一定更好？」每圈功可能更接近準靜態，但功率可能下降；不同條件也不保證單調。
- 「效率為何不是 Carnot？」沒有再生器，升溫包含兩個動能方向的吸熱，直接換浴有不可逆性。
- 「4 次快速掃描能當精確驗證嗎？」只適合探索；正式使用較多獨立重複，檢查熱化與步長，保留不確定度。
