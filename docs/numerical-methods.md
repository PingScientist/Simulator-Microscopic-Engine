# 數值方法、統計與可重現性

## 積分與獨立記帳

一步採「固定位置控制參數更新半步 → 以中點參數執行 BAOAB → 控制參數更新半步」。BAOAB 依序半步受力、半步漂移、整步 OU 熱浴、半步漂移、半步受力。每段循環以整數物理步精確結束。

OU：c=exp(−γdt/m)，v+=c v−+sqrt[Tb(1−c²)/m] ξ。熱量直接是此子步的動能差。每個粒子每方向使用獨立標準高斯值。

固定位置的位能差給出控制功；奇數階段是曲率功，偶數階段是平移功。漂移時作精確自由漂移反射／週期回捲；不把越界位置夾回邊界。

同時獨立累積固定參數機械子步能量變化扣掉 OU 熱，作為數值功。R=ΔE−Win−Qbath 不強制歸零。R 應與累積數值功一致，但記帳閉合本身不是物理正確性的證明。BAOAB 的有限步長動能偏差仍需檢查。

參考：[Leimkuhler & Matthews (2013)](https://arxiv.org/abs/1304.3269)；[Sivak et al. (2013)](https://journals.aps.org/prx/abstract/10.1103/PhysRevX.3.011007)。

## 亂數與續接

使用 Mulberry32 的 32-bit 狀態、開區間均勻數及 Box–Muller 高斯生成器；保存高斯 spare。seedFor 對基礎種子、掃描點、重複索引做固定整數混合。這是可重現的偽亂數流，不宣稱數學上的真獨立或適合無限長軌跡。

畫面、圖表、主題與滑鼠不消耗科學亂數。主實驗與各個掃描重複各自持有 RNG。搬運和相同排程的固定中心對照採共同種子，使用配對差；不同重複之間仍以不同種子初始化。

JSON 保存粒子、種子與當前 RNG、備用高斯值、循環相位、步數、功熱、軌跡、完整逐循環紀錄、掃描、快照與筆記。驗證完成後才原子置換原實驗。同一版本同一引擎可精確續接；跨引擎三角函數與浮點末位可能不同。

## 掃描設計與不確定度

掃描最多使用 64 粒子，依設定 R=4/20/40 次獨立重複，每次至少丟棄 2 圈，再記錄 K=3/5/10 圈。先把一個重複中的 K 圈取平均，再對 R 個重複均值計算樣本 SD、SEM 與 95% Student t 區間。相鄰循環不假設獨立。主實驗的循環 SD 只描述波動，不稱其為獨立重複 CI。

線性擬合為含截距的普通最小平方法，顯示斜率 SE、截距、R² 與點殘差；沒有強迫通過原點，也沒有用理論線造資料。斜率 SE 是 OLS 的描述量；異方差點的更完整推論可用匯出資料另外加權分析。

勾選慢速排程時，溫差、曲率比與邊界掃描統一使用 ramp=100、hold=20。這提高接近準靜態的程度，但不保證所有參數都已充分熱化。其他掃描依各自定義改變變因；每點實際設定全部保留。

- 溫差：固定 Tc、曲率端點，Th=Tc+[0,.5,1,1.5,2,3,4]。
- 曲率比：固定 κmin，r=[1,1.4,2,3,4,6]，超過 κ 上限的點略去並以實際點表為準。
- 速率：ramp=[4,8,15,30,60,100]，端點固定。
- 曲率尺度：端點同乘 [.5,.75,1,1.5,2]，保留有效範圍；必要時減小 dt。
- 搬運：距離固定，hold=[3,5,10,20,40]；每點重跑相同時序的固定中心對照。
- 邊界：兩模式各掃 L=[8,12,18,24,36]。

效率取平均功／平均高溫吸熱，未呈現效率 CI；功率的 CI 由功的 CI 除以固定的循環時間。

## 理論參考與獨立驗證

實際位能的配分積分用 1024 等分 Simpson 法。測試另以細網格高斯積分與週期模型 Bessel 級數交叉檢查。有限速度功熱與獨立的連續時間諧和矩方程比較，矩方程由 RK4 推進，不使用 BAOAB 的更新公式。

測試直接讀取交付 HTML 中的核心。參數導數以中心差分檢查；平衡矩、OU 鬆弛、dt 細化、無驅動／等溫控制組、重現、反射、週期接縫與正式掃描均各自驗證。

## 排程、容量與資料限制

主實驗分批執行，每幀約 8 ms 軟計算預算，圖表與統計約 200 ms 更新，完成、暫停、匯入時完整刷新。進度不由牆鐘補算；背景主實驗會暫停。掃描 Worker 每批約 12 ms，備援約 7 ms，使用同一個 EngineJob 與 Engine.Sim。

取消終止 Worker／備援，revision 拒收舊結果。保存全部完成點及其重複與循環，未完成點不納入擬合。

N≤512；主實驗到 1000 圈自動停止；每圈最多 500 個顯示軌跡點，僅畫最多 160 顆粒子；所有粒子每一步都參與積分與記帳。僅保存顯示用集合軌跡與逐循環功熱，不保存所有粒子的完整逐步路徑，也不提供自由粒子繞行距離。

dt∈[.002,.05] 並要求 dt sqrt(κmax/m)≤.081 及 γdt/m≤.2；這些是支援範圍限制，不是誤差的普遍保證。極長軌跡受有限週期 PRNG 限制，本版以有界教學實驗為用途。

無網路套件、外部字型、CDN、資料 API 或 AI API。原生 Canvas 與系統字型無第三方執行依賴。

JSON 匯入與匯出上限為 32 MiB；超出時須先匯出資料並移除舊快照。掃描快照不重複序列化同一份點資料。
