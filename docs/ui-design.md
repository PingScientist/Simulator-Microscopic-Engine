# 2026-10 介面設計與版本變更

使用 UI/UX Pro Max 技能檢索設計、圖表與可及性指引，再依物理實驗室的使用流程選擇版面。單一 HTML、系統字型、原生 Canvas，沒有 CDN 或新增執行依賴。

## 視覺與操作

- 暖紙白 #f5f3ec、墨綠 #18392f、實測綠 #22694e；深綠粒子儀表形成主視覺。熱浴赭色、冷浴藍、理論金、擬合紫，用圖例與文字輔助辨識。
- 襯線標題與等寬數字，薄分隔線、克制圓角、清楚的內容層級；保留深色主題。
- 第一屏直接提供正功、快慢操作、兩張線性圖、雙週期與證據入口。五分頁保留原四個工作區，新增作業證據；鍵盤 Home／End／左右鍵依實際分頁數運作。
- 小螢幕收斂主標與公式，圖表單欄、參數雙欄；保留至少 44px 的主要控制高度與 reduced-motion。
- 實驗停止、批次完成、取消、存檔載入都從產品流程刷新畫面。切換實驗結果時，條件標籤取自該結果。

## 新增功能

1. 正功驗證：20 次獨立重複，顯示平均、95% CI、實際條件；依區間是否完全大於零呈現結果，不硬寫「成功」。
2. 兩張正式圖連續執行並保存，可取消後續工作；完成證據與目前掃描分開保存。
3. 每粒子／整個系統的功切換、2200×1440 白底 PNG、對應 CSV，方便後續自行撰寫 PDF。
4. 固定曲率換浴示範，展示熱浴與粒子溫度的不同；不增加假造動畫或速度縮放。
5. JSON 保存完整證據，支援舊存檔；每類最近完成結果與六個一般快照各自有界。

新版評分為 1% + 0.5% + 0.5%，雙週期是 Bonus 0.5%。PDF 的文字與編排未在此版本製作；網站也不預填驗證資料。驗收數據與已測範圍見 validation.md。
