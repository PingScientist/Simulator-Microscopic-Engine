## 已知限制與未測範圍

- 沒有實測原生 Safari、Firefox、Edge、實體 iPhone／Android 或低階硬體的長時間效能；WebKit 不等於使用者的原生 Safari，viewport 不等於實體手機。
- 沒有聲稱所有支援參數的笛卡兒積、最長掃描、每種錯誤環境皆已測過。更極端的弱阱／窄域／快速搬運須個別檢查熱化與步長收斂。
- 主實驗相鄰循環可能相關；其 SD 不是獨立重複 CI。OLS 的斜率 SE 未做異方差修正，效率也未計算 CI。
- 科學 PRNG 為有限狀態偽亂數。教學實驗有容量上限，不適合作無限制的長軌跡研究。
- JSON 保存續跑所需完整當前狀態及逐循環資料，沒有保存每一粒子每一步的完整歷史路徑；跨瀏覽器可能有浮點末位差異。
- 平滑週期模型與硬牆諧和模型的全域位能不同，不能把兩者的所有差異只歸因於邊界。
