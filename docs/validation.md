## 平台與物理驗證

- Chromium 151.0.7922.34／Playwright 1.62.1：全新 context、file://、offline=true、攔截 HTTP(S)。
- WebKit 26.4／Playwright 1.59.1：全新 context、file://、攔截 HTTP(S)；不使用與本環境 file 導覽不相容的 offline=true。
- 兩者所有瀏覽器檢查皆零 HTTP(S) 請求、零未捕捉錯誤。
- Node.js v23.5.0，22 組數值檢查重新通過：平衡分布與等分配、獨立 OU 鬆弛、連續矩方程功熱、步長收斂、有限域配分函數、週期接縫、控制參數導數、等溫／無驅動控制組、種子續接、極端配置與六種原有掃描。
- 原生 Safari、Firefox、Edge、實體手機與低階硬體長時間效能未測。WebKit 不等於原生 Safari，viewport 不等於實機。
- OLS 斜率 SE 未校正異方差；高 R² 本身不證明準靜態。主實驗循環可能相關，SD 不當作獨立 CI。平滑週期與硬牆諧和的全域位能不同。
