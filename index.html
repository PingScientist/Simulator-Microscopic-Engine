01 / THE BATH

指定的是熱浴，不是每顆粒子的速度

我們追蹤二維粒子的位置與速度。位能把粒子拉向阱中心；摩擦使它減速；隨機踢擊則補入熱擾動。這三者共同決定實際運動。

dr = v dt
m dv = −∇V dt − γv dt + √(2γkBTb) dB

dB 是 Wiener 增量，變異數為 dt，振幅尺度為 √dt。γ 的量綱是質量／時間，速度衰減率為 γ/m。熱浴在整個容器均勻，依階段切換；不是空間溫度梯度。

三種不同的量
Tᵦ 是設定；Tₖ = K/(Nkʙ) 是二維動能尺度，含漂移；速度散布溫度扣除了集合平均漂移，使用 N−1 修正。N=1 時不定義即時集合散布溫度。強烈非平衡時，不把任何一個估計當作唯一熱力學溫度。

單位：m = kʙ = 1，Lᵧ = 12。長度、能量、時間皆為約化單位。粒子彼此無交互作用，y 方向無位能，仍具有動能與熱容量。

02 / THE WORK

只對外部控制的改變記功

V = ½ κ(x − x₀)²
δWin = ∑ [½(x − x₀)² dκ − κ(x − x₀) dx₀]
ΔE = Win + Qin，Wout = −Win

第一項是曲率功，第二項是平移功。粒子在固定阱裡移動造成的位能變化，不全部算成外界做功。對投影片 −X dλ 的記法，X = −∂V/∂λ。

高溫時分布較寬，放鬆曲率可取出的功較多；低溫時分布較窄，收緊所付出的功較少。兩者相減形成淨輸出功。

Wout,qs/N = ½ kB(TH − TC) ln(κmax/κmin)

此式限於固定中心、無限域諧和阱的準靜態曲率循環。硬牆很近、週期位能不夠局域或操作太快時，使用所選模型的參考，並觀察偏離。

從配分函數到循環功

Z₁ ∝ T3/2 κ−1/2，因此同溫下 ΔF/N = ½ kʙT ln(κ₂/κ₁)。高溫放鬆與低溫收緊的自由能差取負後相加，得到上式。有限域改用 Zₓ = ∫ exp[−V(x)/(kʙT)] dx；頁面以 Simpson 積分計算實際模型參考。

03 / THE BOUNDARY

跨界的必須是同一個物理世界

硬牆模式在 x 方向作彈性反射，固定牆不做功。雙週期模式把兩端連接，並採用平滑的週期位能：

Vp = κLₓ²/(4π²) [1 − cos θ]
θ = 2π(x − x₀)/Lₓ

阱底曲率仍為 κ；位能、力和參數導數跨界連續。粒子穿過畫面邊緣不會產生額外功。平移中心使用連續排程，沒有瞬間回捲的假功。

此比較同時改變邊界與全域位能形狀，不將差異全部歸因於硬牆。Lₓ 增大、粒子局域在阱底時，週期模型逐漸接近諧和近似。

週期模型的功與參考
∂Vp/∂κ = Lₓ²/(4π²)(1 − cos θ)
∂Vp/∂x₀ = −κLₓ/(2π) sin θ
Zₓ = Lₓ e−aI₀(a)，a = κLₓ²/(4π²kʙT)

平衡配分函數不依中心位置；有限速度搬運仍可能有耗散。參考不從模擬點擬合產生。

04 / FINITE TIME

慢，要相對於鬆弛時間

曲率與位置改變的時間，必須比粒子分布調整的時間更長。曲率大會提高振動頻率；摩擦太小不易熱化，摩擦太大也可能讓位置變化變慢。

εκ = τrel |κ̇|/κ
εx = τrel |ẋ₀|/σₓ

局部諧和近似下 σₓ = √(kʙT/κ)。這些是診斷尺度，不能取代實際鬆弛與收斂測量。「播放速度」只影響觀看速度；「曲率操作時間」才改變物理過程。

把每圈功做大，與把每秒功率做大，是不同問題。無限慢時每圈仍可能有有限功，但功率趨近零。

搬運採平滑起停，D/τ 是平均速率，峰值為其 1.5 倍。搬運掃描同時演化相同時間安排的固定中心對照，使用配對種子；各重複仍彼此獨立。

05 / ENERGY ACCOUNTING

熱量獨立記帳，誤差不藏起來

積分採 BAOAB：半步受力、半步位移、熱浴、半步位移、半步受力。控制參數在兩端以對稱半步更新，功由固定位置的位能差計算。

v⁺ = c v⁻ + √[(kʙT/m)(1 − c²)] ξ
c = exp(−γΔt/m)，ξ ∼ N(0,1)
Qbath = K⁺ − K⁻

R = ΔE − Wᵢₙ − Qᵦ 是有限步長的殘差。另累積機械子步能量誤差，檢查帳本閉合；不把 R 加回熱量讓結果看似完美。

06 / EFFICIENCY

升溫的熱，也要算進去

η = ⟨Wout⟩ / ⟨QH⟩
P = ⟨Wout⟩ / τcycle

本模型沒有再生器。Qʜ 包含升溫及高溫放鬆兩段的淨吸熱；不只累加正的微小熱增量。先平均再取比值，且只在平均功與 Qʜ 都為正時顯示效率。

固定中心、諧和極限的參考效率

二維動能加一個諧和位能自由度，使 E/N = 3kʙT/2。令 r = κₘₐₓ/κₘᵢₙ：

ηqs = (Tʜ − Tᴄ) ln r / [3(Tʜ − Tᴄ) + Tʜ ln r]

這不是 Carnot 效率。固定曲率直接換浴仍有不可逆熱交換；不同邊界的熱容量也可能改變。
