# 微觀引擎參考報告

[開啟 PDF](微觀引擎-參考報告.pdf)

依新版簡報第 9–11 張與評分項目整理，作為閱讀與討論的參考稿。內容包含控溫與溫度定義、控制功、正功證據、三種準靜態變因、兩張線性關係圖與雙週期邊界。本文的數值來自 Langevin 模擬，不是實驗室實測。公式、內文符號、表格數學與圖表座標均由 LaTeX 排版；`latex/main.tex` 為可編輯原稿，兩張圖由 PGFPlots 繪製。現行版式採中文學術報告：標楷體、單欄正文、不含摘要，保留簡單置中標題、連續編號公式、中文圖表說明及參考文獻。黑白圖表以點形與線型區分資料與理論，沒有彩色色塊或裝飾頁首。

本版維持五節結構，以三張表格整理準靜態參數、線性擬合及邊界模型的比較，保留必要公式、正功證據、誤差定義與適用限制。標題下方不列日期；各節標題前後留白統一為 12 pt 與 4 pt，正文維持 11 pt、單欄與至多四頁。

- 兩張線性圖：`../docs/verification/2026-10-22/formal-temperature.json` 與 `formal-ratio.json`；每點 N=32、20 次獨立重複，各暖機 2 圈再平均 3 圈。兩組正式掃描於 2026-10-23 完整重跑，逐點、逐次與逐圈均重現原記錄；交付仍引用原資料。
- 2026-10-22 補跑：`quasistatic-data.json`，直接讀取 bd51397 的 `index.html` 中 engine-core 與 engine-jobs。共 26 個掃描點、520 次獨立重複，保留暖機及配對對照共 4,340 圈原始記錄。曲率時間、曲率尺度、搬運各使用 N=32、R=20、K=5；邊界掃描另使用曲率段 100、換浴段 20。
- 所有均值先在同次重複內平均，再計算跨重複的 95% t 信賴區間；PDF 擬合表中的 SE 是 OLS 斜率標準誤。圖為向量圖，可放大閱讀；沒有放大誤差棒或以理論生成資料點。
- 補跑各掃描的完整點集都保留；報告表格只摘列端點比較，未刪除不利結果。快速搬運的平均淨功為負。

## 重製

從 repo 根目錄執行：

```sh
node reports/collect.cjs
python3 reports/generate_report.py
```

第一行會重算補跑資料；若只重新排版既有結果，只執行第二行。本次稽核重跑驗證，但保留原始模擬資料；重排報告仍直接使用原 JSON。

產生器需要 Python 3、`pypdf` 與 Tectonic。它會優先使用 PATH 中的 Tectonic，或此 macOS 上 ChatGPT 應用程式隨附的編譯器；也可用 `--tectonic /path/to/tectonic` 指定。原稿使用 `fontspec`、`xeCJK`、`amsmath` 與 `pgfplots`，中文字型為 DFKai-SB（標楷體，本機為 `/Library/Fonts/Kaiu.ttf`），西文字型為 Times New Roman；數學式使用 LaTeX 數學字型。中文字型已嵌入交付 PDF。其他平台需在原稿中改成可用的字型；Tectonic 初次編譯可能下載 TeX 套件。閱讀交付 PDF 不需安裝這些依賴。

腳本先核對數值核心 hash，再從原始 JSON 產生 `latex/data/` 的數據巨集和 CSV；圖表保留原始精度，表格才做顯示用四捨五入。`--prepare-only` 可只更新這些資料。`latex/` 也可直接在 LaTeX 編輯器開啟，以 XeLaTeX 或 Tectonic 編譯 `main.tex`。隨附的產生器會在暫存資料夾編譯，確認為 1–4 頁 A4 且沒有缺字或超出版面的警告後，才更新上層 PDF；暫存檔及其資料夾會自動移除。

此環境的 Codex 內建預覽目前無法讀取系統字型；本報告已由 Tectonic 命令列成功編譯，交付 PDF 的閱讀不受影響。

`validation.json` 記錄交付 PDF 的頁數、hash 與檢查範圍。模擬資料的圈平均、跨重複平均、95% CI 與配對差已於資料產生時另行核對。本次另完成以下內容稽核及 22 組數值測試，並檢查 LaTeX 編譯、字型嵌入、報告排版、標題留白及日期移除。網站程式沒有修改，瀏覽器操作測試未重跑。

`audit-data.json` 記錄獨立核算結果：40 個參數點、800 組主要重複及 100 組配對對照，共 5,780 圈記錄。逐圈檢查功熱記帳，再重新計算平均、樣本標準差、Student t 區間、配對差、效率、功率與 OLS。硬牆配分函數另以 Gaussian erf、週期模型另以 Bessel I0 檢查，不沿用核心的 Simpson 積分。核心 t 表將自由度 19 的臨界值四捨五入為 2.093；與獨立積分值的 CI 相對差約 0.00115%，不影響報告所列 CI 的末位。

另以目前 HTML 重跑每個參數點的第一組保存種子及所有相應對照，共 45 組、289 圈；最大差為浮點末位。兩個正式線性掃描完整重跑，JSON 中的全部結果均與原資料相同。`audit-numerical.json` 保存本輪 22 組數值檢查，涵蓋平衡、熱浴、力與參數導數、週期接縫、獨立矩方程及時間步收斂。該測試的正功基準每次記錄 3 圈，報告則採 5 圈，因此兩個均值不應直接當成相同設定。
